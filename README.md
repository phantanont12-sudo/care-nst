## ลองใช้ทันที (โหมดทดลอง)
เปิด `index.html` โดยไม่ใส่ค่า Firebase จะเข้าโหมดทดลอง ข้อมูลอยู่ในเครื่องนั้นเท่านั้น เปลี่ยนบทบาทได้จากแถบสีเหลืองด้านบน ใช้ฝึกครูก่อนรับตัวได้

## ติดตั้งใช้งานจริง (ครั้งเดียว ~20 นาที)

### 1. Firebase
1. [console.firebase.google.com](https://console.firebase.google.com) → โปรเจกต์ `cho1pan52` (หรือสร้างใหม่)
2. **Build → Authentication → Get started → Email/Password → Enable**
3. **Build → Realtime Database → Rules** วางเนื้อหาไฟล์ `database.rules.json` ทั้งไฟล์ → **Publish**
4. **Project settings (เฟือง) → Your apps → Add app → Web (</>)** ตั้งชื่อ → คัดลอกค่า `firebaseConfig`
5. เปิดไฟล์ `firebase-config.js` แทน `null` ด้วยค่าที่คัดลอกมา

> ข้อมูลเดิมของผลัด 1/69 อยู่ใต้ `units/...` Rules ใหม่จะปิดไม่ให้ใครอ่านได้ ถ้าต้องการเก็บไว้ ให้ Export JSON ก่อน

### 2. GitHub Pages
1. สร้าง repo ใหม่ เช่น `care-nst` (Public ได้ เพราะไม่มีข้อมูลบุคคลในโค้ด)
2. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้
3. **Settings → Pages → Branch: main / root → Save** รอ 1–2 นาที

### 3. ผู้ดูแลคนแรก
1. เปิดแอป → **สมัครใช้งาน** ด้วยอีเมลของผู้ฝึก
2. Firebase Console → Realtime Database → Data → `users` → เปิดรายการของตัวเอง → กด **+** เพิ่ม `role` = `trainer`
3. รีเฟรชแอป จากนั้นครูคนอื่นสมัครเอง แล้วผู้ฝึกกำหนดบทบาทที่ **ตั้งค่า → ผู้ใช้และสิทธิ์**

### 4. นำเข้ารายชื่อ
หน้า **ทหารใหม่ → แบบฟอร์ม Excel** กรอก แล้ว **นำเข้า Excel** (นำเข้าซ้ำได้ จับคู่ตามลำดับ)
